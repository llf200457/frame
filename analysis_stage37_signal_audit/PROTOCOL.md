# 第37阶段：测量质量与细胞组成敏感性（训练前锁定）

只检验实测AT8阳性面积的log1p终点。沿用497组合、84供体、9脑区；seed2026和2027；每个种子9脑区×5外层折，内外层同时排除供体和脑区。冻结第35阶段所有筛选与参数网格。

两个新方案：六项原始metadata加测量/组成指标的Ridge（quality_only）；相同指标加两类细胞各10个训练内筛选基因的ElasticNet（quality_gene）。与相同种子旧metadata、pooled预测配对比较。共180个外层模型。

附加指标：每细胞类log1p核数、log1p总UMI/核数、MT-基因占总UMI比例；官方观测表四项GEX指标以核数加权汇总；各Supertype的核数份额（固定按字典序去掉第一类，防和为1冗余）。Micro-PVM只纳入名称以Micro-PVM开头的观测。不加入Braak、CERAD、AT8或其他疾病/病理/认知标签。份额是捕获核中比例，不能称为体内细胞丰度。

原始输入转化逐条独立；缺失填补、标准化、基因筛选只在各训练集拟合。质量指标可能与病理有生物关联，因此调整后下降不证明原模型全部是技术混杂。

补充分析：已有三种子OOF预测先在同一组合求平均；供体和脑区加性固定效应残差化真实值与预测值，描述供体内相对脑区病理差异的关联；2000次供体簇bootstrap重新拟合固定效应，报告描述性相关区间，不把此操作当部署校准或训练步骤。不同OOF折模型存在差异，因此这不是因果或独立验证。

按供体簇bootstrap比较新旧模型宏MAE，条件于已拟合模型；不重训练bootstrap、不控制此前探索选择。所有结果包括失败脑区完整保存；不改当前论文源文件，不把普通ElasticNet称为新算法。
