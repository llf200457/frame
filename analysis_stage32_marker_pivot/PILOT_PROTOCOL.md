# Exploratory marker pivot feasibility protocol, before fitting

2026-09-30. Independent measured proteins/cognition in GSE270454 are paper-reported, but individual paired labels were not found in downloaded SOFT/GitHub/supplements. Do not reconstruct individual values from aggregate tables, figures or diagnoses. The following target is an explicitly RNA-derived molecular readout, not protein concentration, disease probability or measured retrotransposition events.

RNA count matrix: GSE270454, 27,663 rows, 45 participants. Primary exploratory target = average of log2(count+1) for L1HS:L1:LINE and LTR5:Hs:ERVK:LTR minus mean log2(count+1) for five fixed reference genes TBP,HPRT1,PPIA,RPLP0,RPL13A. Normalization is operational; reference stability is not established here. Repeat subfamilies were prespecified from published biological context, not selected from the cohort's diagnostic DE lists. Because the same dataset was used in prior TE literature, it is not a genuinely independent validation of those marker definitions.

Predictors: a fixed 30-gene interferon-response/sensing panel (DDX58,IFIH1,MAVS,TBK1,IRF3,IRF7,STAT1,STAT2,ISG15,IFIT1,IFIT2,IFIT3,MX1,MX2,OAS1,OAS2,OAS3,OASL,RSAD2,IFITM1,IFITM2,IFITM3,USP18,IFI6,IFI27,IFI44,IFI44L,DDX60,BST2,GBP1). This curated panel is exploratory, not a formally validated clinical signature. Use within-individual coding-gene ranks computed over all gene-symbol rows without ':'; exclude reference genes and any target rows. No target TE or reference-gene expression enters predictors. Same-library measurements can still share biological/technical sources despite disjoint feature sets; no independent clinical validation is implied.

Comparators: training-mean target; age/sex/log coding-gene-counts ridge; mean fixed immune-panel rank ridge; 30 panel ranks ridge; covariates plus panel ranks ridge. Ridge alpha=[1,10,100], three inner folds, five outer folds stratified by the four original groups for balance only; diagnosis never a model input. Three split seeds20260930/20261001/20261002. All scaling/tuning training-only. Report pooled outer R2, MAE, Pearson/Spearman, relative to training-mean and covariate baselines. Three seeds reuse45 participants and are not independent validation. Small sample correlation or in-sample fit cannot justify biomarker claims.

Target sensitivity: reference-gene-free depth-offset normalizer using log2(sum coding-gene counts + 1)-log2(1e6), instead of the five reference genes. Report agreement of the two target definitions; high correlation of normalized features/targets is not proof of independent biological association. If changing normalization alters findings, report fragility. Advance only if meaningful out-of-fold R2/MAE improvement over baselines is consistent. Otherwise do not call the readout predictable or elevate this pilot to the primary paper route. This finite pilot is not an algorithm novelty claim.
