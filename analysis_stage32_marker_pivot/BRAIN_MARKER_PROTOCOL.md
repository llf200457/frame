# 病理实测指标探索协议

在拟合前登记。数据：GSE106241，60份下颞叶脑组织表达；Aβ42及分泌酶活性各55份有实测值。用途为脑组织分子病理研究，不能据此宣称血液筛查。

- 主探索终点：log(1+Aβ42实测值)。辅助终点：Braak分期；仅探索性按0–6数值回归，尚不等同序数模型。beta-secretase活性为第三个探索性终点，取log(1+x)。不使用其他病理指标或诊断作为输入。
- 比较：训练均值；年龄、性别、RNA质量类别、APOE4拷贝数；表达；表达加上述信息。
- 表达：固定可用基因集合内逐样本排名，训练折内方差选300基因、3维PCA。RNA质量属于类别，性别类别；年龄和APOE拷贝数作为数值。所有填补、尺度变换、PCA在训练折拟合。
- 验证：3个预先固定种子（2026、2027、2028），5折外层、3折内层；岭回归强度10/100/1000在内层按MAE选择。三个重复不是独立样本。
- 评价：外层合并预测的R²、MAE、Spearman；与均值及元数据比较。Braak额外报告四舍五入并截断后的误差，不把回归当成确诊或时间进展预测。
- 本数据已由提交者进行全队列分位数归一化及探针筛选，无法声称原始预处理完全独立。本轮只能决定候选是否值得独立来源检验，不能形成临床有效性结论。
- 如表达不优于简单信息模型，保留负结果，不更改终点或大量试模型后挑选最好数字。未经独立来源验证，不将候选写入论文已证实结果。
