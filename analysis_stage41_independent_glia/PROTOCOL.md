# Independent glial RNA-component transport pilot: lock before expression processing (2026-10-01)

GSE160936: original Smith et al. Acta Neuropathologica, DOI 10.1007/s00401-021-02372-6, PMID34767070. GEO SOFT metadata downloaded and inspected in stage40; no external RNA/pathology associations computed before this protocol. Twelve independent UK brain donors, each EC/SSC; 24 samples, not 24 people. Real endpoint is % pTau-positive cells (AT8 immunostaining), not SEA-AD % AT8-positive area. Sources differ in region, sampling, glial enrichment and pathology units.

## Scope and frozen object
Existing stage39 frozen 20-gene ElasticNet bundles for Tau_panel and Tau_DFC are untouched. Full 30-covariate model cannot be directly validated because all quality/subtype/APOE/PMI inputs are unavailable in GEO. Extract ONLY its frozen RNA component s(x)=target_SD * sum_j beta_j (log2(1+CPM_j)-training_mean_j)/training_SD_j over the 20 RNA columns. This is a transported expression score, not the whole predictor and not a calibrated pTau-percent prediction. No external target-dependent fitting, reorientation, feature selection, rescaling or recalibration. A score failure must remain failure. Also remove MT-prefixed contributions without refitting as a fixed sensitivity check. Missing required Ensembl gene is fatal; observed zero counts are retained.

## Operational cell annotation
Original authors' portal returned HTTP502, and GEO exposes raw filtered count matrices without barcode-level cell labels. Use outcome-blind canonical marker annotation as an explicit operational pilot; do not label it original annotation or independently validated cell identity.
Nucleus QC: detected genes >=200 and <=6000, UMI <=25000, mitochondrial count fraction <=.05. Do not discard MT counts from CPM denominator.
Fixed panels: Astro AQP4,GFAP,ALDH1L1,SLC1A3,SLC1A2,GJA1; Micro/PVM P2RY12,TMEM119,CSF1R,C1QA,C1QB,TYROBP,PTPRC,AIF1,LAPTM5; Neuron SNAP25,RBFOX3,SYT1,SLC17A7,GAD1,GAD2; Oligo MBP,MOG,PLP1,MAG,MOBP; OPC PDGFRA,CSPG4,VCAN,OLIG1,OLIG2; Vascular CLDN5,FLT1,KDR,PECAM1,RGS5,PDGFRB. These are canonical identity panels, not AD/tau-selected features. Score = mean log1p(CP10k) over panel genes; annotate highest score only if at least two panel genes detected and winning margin >=.25. Keep other nuclei unclassified. Sum raw counts per sample/class, >=20 nuclei/class. Confirm marker distributions and record exact class counts/barcodes. This broad Micro/PVM mapping is not exact SEA-AD supertype harmonization. A sensitivity with winning margin >=.50 is locked before results, to check annotation robustness (not model tuning).

## Statistics
Primary external directional assessments: Spearman frozen all-gene RNA component versus log1p measured pTau in EC (one independent donor/sample). Report both panel/DFC scores. SSC tests are auxiliary; donor-paired EC-minus-SSC score versus pathology difference is an additional regional transport diagnostic. Both components (all/without MT) x two frozen targets x three comparisons = 12 tests, BH family. CIs bootstrap 4000 donors conditional on frozen scores; n small and precision limited. No pooling 24 rows as independent subjects. If pathology, input, missing genes or annotation prevent testing, document the concrete failure and do not make validation claims. Scores from marker-margin .50 are sensitivity only (12 additional contrasts, separate BH family explicitly).

Independent RNA-component association can support direction transport, but cannot prove full-model clinical validity, AT8-area calibration, or algorithm novelty. Conventional RF/internal learning remains a separate benchmark, not this frozen score. Do not train a model on these twelve external outcomes in this run.
