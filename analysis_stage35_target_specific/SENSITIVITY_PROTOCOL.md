# 去线粒体特征敏感性检查

在首轮监督模型完成、检查基因频率后登记。高频选择包括MT-ND4L、MT-ND4、MT-CYB、MT-ATP8，可能与生物学或样本质量相关；现阶段无法把它们解释为AD机制。

为检查改善是否完全依赖这类特征，另运行一次pooled弹性网，筛选候选中预先排除符号以MT-开头的基因。保留原CPM分母和所有供体、脑区、终点、验证划分、选基因数量及参数网格；不得依据结果再添加其他排除。排除MT基因不等于排除了全部RNA质量混杂。结果明确为看到首轮选择后的探索性敏感性分析。

只拟合该敏感性候选，复用主轮的元数据/PCA/pooled外层预测作相同记录比较，两个终点均报告。保存选基因、划分及实际预测。若信号消失，应进一步核查区域/文库质量，不把第一轮结果包装成独立病理机制。
