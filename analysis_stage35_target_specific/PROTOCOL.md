# 第35阶段：目标特异监督表示与脑区差异

2026-09-30，模型拟合前登记。固定84供体/497组合/9脑区，外层划分及种子2026沿用第34阶段；两个终点log(1+6E10%)、log(1+AT8%)各自调参、拟合，不共用秩一表示。

比较4个方案：元数据岭回归；元数据+每类3PC的目标特异岭回归；元数据+监督筛选基因的弹性网（pooled）；元数据+训练脑区内关联筛选基因的弹性网（within-region）。后两种每类预筛训练供体加权方差前1000基因，再按加权关联绝对值固定取10基因，合计20基因及6个元数据。输入逐样本log2(1+CPM)，不使用病例诊断、病理分期、认知或另一终点。

pooled关联直接由训练表达与终点计算；within-region关联在训练脑区内对表达与终点各自加权去均值，再计算关联。脑区标签只用于训练特征筛选，不将测试脑区标签/分布用于中心化。最终回归仍拟合绝对log尺度，去均值不是测试脑区截距校准，不能保证处理全部区域偏移。

供体训练权重w_i=1/该供体训练记录数，基因方差、关联、输入尺度、目标尺度及最终损失使用该权重；PCA预筛300基因和PCA采用与第34阶段相同的记录等权方式，仅最终尺度及损失供体加权，作为方法控制而非新贡献。

外层每次留一整个脑区及一折供体。内层将剩余供体固定3折、训练脑区按字母排序分成3组；第j个内层验证同时留出供体折j与脑区组j。训练排除验证供体的全部脑区，也排除验证脑区的全部供体，测试则取两者交集。这是加强的调参规则：本轮应先与同规则元数据/PCA比较，不能把相对第34阶段的差异全归因于模型改变。

岭强度10/100/1000；弹性网l1_ratio固定0.5、alpha固定0.01/0.1/1，在训练目标标准化后按内层MAE选择。每方案每终点均3个参数配置，不事后扩网格。全部选择仅内层训练进行，3个内层验证折MAE等权平均。候选预算360个外层模型；预期3976条预测。

弹性网目标：min_b [Σ_i ŵ_i(y_i-a-x_iᵀb)²/(2n)+α{ρ||b||_1+(1-ρ)||b||²/2}]，ρ=0.5，ŵ_i归一化到和n。加权关联c_g=Σ_iw_i(g_i-ḡ)(y_i-ȳ)/sqrt[Σ_iw_i(g_i-ḡ)²Σ_iw_i(y_i-ȳ)²]；within-region把全局均值替换成训练脑区均值。两者均既有方法，本轮是检验任务表示和迁移可行性，不直接宣称算法创新。

报告每脑区MAE/R²/Spearman及9脑区宏平均，条件区间按同供体跨脑区共同重采样。模型已基于上一轮结果选定，所有结果均为探索性，未独立外部验证。记录每个模型基因、参数、供体、脑区、软件版本及输入哈希，报告收敛警告。比较全部脑区，不剔除V1C。主稿暂不改写。
