# Data availability and upstream reuse

`data_sources.csv` lists accession pages and exact input URLs recovered from actual download records. Historical hashes refer to files retrieved during analysis, not to a new download in this packaging round. Catalogue rows are information links; download rows identify actual files. SHA256 and byte counts are never inferred from an unexecuted HEAD request.

The repository supplies author-generated aggregate results and fixed model definitions. It excludes participant-level expression, covariates, CBC/pathology outcomes, subject identifiers, raw H5AD/FASTQ/count archives and third-party article PDFs/HTML. Gene-level difference tables and performance summaries are aggregate analysis outputs, not fabricated data.

Original input releases remain at GEO, MassIVE and Allen/SEA-AD. Obtain each input directly and follow that provider's access, attribution and reuse terms. Public download availability does not establish the license for redistribution. This package makes no claim that upstream terms were legally re-adjudicated.

Source manifests/protocols preserve hash guards but some protocol-relative inputs are absent. Hash mismatch or missing input is a reconstruction problem to resolve, not a reason to ignore guards. No participant identifier was replaced with a made-up patient or synthetic observation.
