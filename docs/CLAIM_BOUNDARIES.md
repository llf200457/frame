# Result and interpretation boundaries

* Source measured-neutrophil OOF: 125 participants, R² 0.579910, MAE 6.874917 percentage points. Internal resampling is not independent external validation.
* SoundLife: 94 primary participants, 20 calibration/74 evaluation; raw R² -0.120455, offset R² 0.465803, MAE 4.742964. Two-group R² interval [0.177267,0.608195] resamples calibration and evaluation groups conditional on the frozen source model.
* Official MCPcounter offset baseline: MAE gain 0.792949, interval [-0.032034,1.608734]. The interval includes zero; established method superiority is not claimed.
* Related array AUC 0.776764; independent array AUC 0.565171; independent target-relative RNA-seq AUC 0.498866 and 0.721366. These are distinct validation/stress-test roles, not four consistently strong diagnosis results.
* Fixed AD-weighted RNA projection versus measured neutrophil percentage: partial rank r 0.228207, q 0.028676 in healthy SoundLife participants. No paired AD/CBC clinical validation was available.
* Within-person correlation uses repeated visits from the same participants; it does not add independent donors.
* SEA-AD and GSE160936 support tissue-context association and source modelling. The external primary brain association was not consistently confirmed; an auxiliary region does not replace a failed primary endpoint.
* Protein/NF-kappaB work has unsuccessful batch transport. Candidate genetic instruments were screened; MR, colocalization and virtual knockout were not performed.

No training was conducted to improve these results during repository packaging. The README audit checks saved table correspondence and file integrity, not publication eligibility, novelty or journal acceptance.
